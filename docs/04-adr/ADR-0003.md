# ADR-0003: State fidelity honestly (full / partial / compensating)

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
Claiming identical semantics across engines is false (e.g. no SCP key for RDS public access).

## Decision
Every mapping carries fidelity and a documented gap; the parity gate rejects non-full mappings without a gap note.

## Alternatives considered
Claim 100% equivalence; omit hard controls.

## Consequences
Lower headline coverage, higher credibility.
