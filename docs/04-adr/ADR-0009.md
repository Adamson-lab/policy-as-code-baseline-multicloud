# ADR-0009: Exceptions are time-boxed native exemptions

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
Permanent exceptions rot.

## Decision
Azure exemptions with expiresOn; AWS scoped condition; GCP scoped override; all recorded in an exception register with expiry sweeper.

## Alternatives considered
Tag-based self-service bypass; unlimited waivers.

## Consequences
Three mechanisms to operate; one expiry clock.
