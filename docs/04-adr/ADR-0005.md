# ADR-0005: Audit-first rollout; AWS canary OU as dry-run

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
SCPs have no audit mode; Azure has effects; GCP has dryRunSpec.

## Decision
Audit = canary OU + Config on AWS, effect=Audit on Azure, dryRunSpec on GCP.

## Alternatives considered
Enforce directly: too risky; skip AWS audit: inconsistent.

## Consequences
AWS audit signal is weaker than the other clouds.
