# ADR-0006: Bundle SCPs to respect AWS limits

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
AWS allows 5 SCPs per target and 5120 chars each.

## Decision
Generator first-fit packs statements into at most 4 bundles; parity gate enforces limits.

## Alternatives considered
One SCP per control: exceeds per-target limit; manual packing: error-prone.

## Consequences
Bundle churn on any change; Sids keep traceability.
