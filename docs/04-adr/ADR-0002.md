# ADR-0002: Four-layer enforcement

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
No engine sees every attribute at every time.

## Decision
Author-time check, CI gate, cloud control plane deny, runtime detective.

## Alternatives considered
Cloud-native only; CI only.

## Consequences
More layers; resilient to single-layer gaps.
