# ADR-0008: Generated Rego tests plus a Python oracle from shared fixtures

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
Supersedes ADR-0007. Need tests that cannot drift and that run without OPA.

## Decision
Fixtures auto-generated from the rule DSL feed both generated Rego tests and a Python oracle that runs everywhere.

## Alternatives considered
Hand tests (0007); OPA only (not runnable in all environments).

## Consequences
Oracle proves the DSL; `opa test` in CI proves the generated Rego.
