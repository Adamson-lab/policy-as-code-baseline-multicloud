# ADR-0001: One catalogue generates every engine

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
Four hand-written policy sets drift.

## Decision
Control definitions are the single source; generator emits Rego, SCP/Config, Azure Policy and GCP Org Policy.

## Alternatives considered
Hand-write each engine (drift); adopt a commercial multi-cloud CSPM only (lock-in, opaque semantics).

## Consequences
Generator to maintain; provable consistency.
