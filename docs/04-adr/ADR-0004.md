# ADR-0004: Rego targets Terraform plan JSON

- **Status:** Accepted
- **Date:** 2026-11-24
- **Deciders:** Architecture board (author: Favour Adamson)

## Context
Runtime admission (Gatekeeper/Kyverno) is Kubernetes-specific.

## Decision
Rego evaluates `terraform show -json` output in CI; Kubernetes policy is a roadmap extension.

## Alternatives considered
Gatekeeper for everything: wrong layer for IaaS/PaaS.

## Consequences
Pre-deploy only; runtime covered by native engines.
